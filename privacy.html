With You Explorer

Privacy policy

This policy covers the With You Explorer, a test app that reads fictional test patients from Epic’s sandbox.

Last updated 17 November 2026

  • What it reads. The test patient data listed in How the explorer works, from Epic’s sandbox only.
  • Where it’s stored. Only on your own machine, the computer running the explorer.
  • Never shared or sold. Data is not sent to anyone else, and it is never sold.
  • Used only for testing. Data is used only to test and improve the explorer.
  • Deleted when testing ends. All stored data is deleted when testing ends. You can also delete it at any time with Disconnect.
