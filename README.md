# With You

Landing page for **With You**, a voice-first companion for patients and caregivers,
from hospital admission through recovery, until you reach your own new normal.

Live site: https://yeshinin.github.io/with-you/

## Structure

- `index.html` — all page content (sections are marked with `<!-- ===== ... ===== -->` comments)
- `styles.css` — colours, fonts and layout (palette variables at the top under `:root`)

No build step. Edit the files and push to `main`; GitHub Pages redeploys automatically.

## Preview locally

```bash
python3 -m http.server 4310
```

Then open http://localhost:4310.
